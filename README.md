# 📱 نرم‌افزار هوشمند محاسبه درصد، تخفیف و افزایش قیمت (Flutter)

یک اپلیکیشن کامل و مدرن فلاتر برای محاسبات روزمره فروشگاهی، تجاری و شخصی.

## ✨ قابلیت‌ها:
1. **محاسبه تخفیف کالا:**
   - وارد کردن قیمت اولیه و درصد تخفیف.
   - محاسبه خودکار میزان تخفیف (سود خریدار) و قیمت نهایی پس از کسر تخفیف.
   - دکمه‌های سریع برای درصدهای رایج (۵٪، ۱۰٪، ۱۵٪، ۲۰٪، ۳۰٪، ۵۰٪، ۷۰٪).
2. **محاسبه افزایش قیمت و سود / مالیات:**
   - محاسبه قیمت نهایی بعد از اضافه شدن درصد سود، تورم یا مالیات بر ارزش افزوده (۹٪).
   - نمایش واضح سود یا مقدار اضافه شده به قیمت پایه.
3. **محاسبه درصد عمومی:**
   - محاسبه مقدار یک درصد مشخص از یک کل (مثلاً ۲۵ درصد از ۵۰۰).
   - محاسبه درصد یک جزء نسبت به کل.
4. **طراحی و تجربه کاربری:**
   - پشتیبانی کامل از زبان فارسی و راست‌چین (RTL).
   - جداسازی سه رقم سه رقم اعداد و قیمت‌ها (تومان، ریال و عددی).
   - امکان کپی کردن آسان نتایج با یک لمس.
   - بدون نیاز به زدن دکمه محاسبه (محاسبه بلادرنگ و آنی).

## 🚀 نحوه دریافت خروجی APK با GitHub Actions (بدون نیاز به نصب فلاتر)

1. یک مخزن جدید در [GitHub](https://github.com/new) بسازید.
2. در پوشه این پروژه ترمینال را باز کرده و دستورات زیر را اجرا کنید:

```bash
git init
git add .
git commit -m "Initial commit for percent calculator app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```

3. به تب **Actions** در مخزن گیت‌هاب بروید؛ پس از چند دقیقه بیلد با موفقیت تمام شده و فایل **`PercentCalculator-Release-APK`** آماده دانلود است!
